# Snova Studio – Startanleitung

## SCHRITT 1: Kie.ai API-Key eintragen
Datei: C:/Users/rober/ki-app/backend/.env
Zeile: KIE_API_KEY=HIER_DEINEN_KIE_KEY_EINTRAGEN
=> Ersetze mit deinem echten Kie.ai Key

## SCHRITT 2: Backend starten
Terminal in: C:/Users/rober/ki-app/backend/
Befehl: node --experimental-sqlite server.js

Admin-Login:
  E-Mail:   admin@ki-app.com
  Passwort: Admin123!

## SCHRITT 3: IP-Adresse herausfinden
Windows-Terminal: ipconfig
Suche: IPv4-Adresse (z.B. 192.168.1.50)

Datei oeffnen: C:/Users/rober/ki-app/mobile/constants/Config.ts
Zeile aendern: export const API_BASE_URL = 'http://192.168.1.50:3000/api';

## SCHRITT 4: Mobile App starten
1. Expo Go App auf dem Handy installieren (App Store / Play Store)
2. Terminal in: C:/Users/rober/ki-app/mobile/
3. Befehl: npx expo start
4. QR-Code mit Expo Go scannen

## SCHRITT 5: Nutzer erstellen
Im Admin Panel (Profil-Tab > Admin Panel):
- Nutzer anlegen, Coins vergeben
- Nur du als Admin kannst Coins vergeben!
