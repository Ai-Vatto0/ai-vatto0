🚀 SOFORT-PLAN:

1. HTTP-SERVER STARTEN (Windows-Computer):
   cd C:\Users\rober\ki-app\menu-wall-app

   → Variante A (Node.js):
   npx http-server -p 8000

   → Variante B (Python):
   python -m http.server 8000

   → Server läuft unter:
   http://192.168.178.109:8000/index.html
   (IP ggf. anpassen: ipconfig checken)

2. IM LADEN - PRO TV (nacheinander):
   ✓ Stick per HDMI anschließen
   ✓ USB-Strom verbinden
   ✓ WLAN verbinden (Settings → Network → WiFi)
   ✓ Chrome öffnen → App laden:
     http://192.168.178.109:8000/index.html
   ✓ Admin-Button (⚙️) → Bildschirm wählen
   ✓ Menü-Bild hochladen
   ✓ "Anzeigen" → Bild auf TV sichtbar ✓

3. AUTOSTART TESTEN:
   ✓ TV ausschalten
   ✓ 5 Sekunden warten
   ✓ TV anschalten → App sollte automatisch laden

4. FERTIG:
   ✓ Kunde kann morgen TV anschalten
   ✓ Menü-Wand erscheint automatisch
   ✓ Du kannst remote Bilder ändern

⚠️ WICHTIG:
- Alle 3 Menü-Bilder in **EINER** Auflösung (z.B. 1920x1080 jedes Segment)
- Jeder Stick muss **einzeln** konfiguriert werden
- WLAN muss stabil sein (test mit mehreren Geräten)
- Admin-Panel (⚙️) = nur für Setup, dann ausschalten

📞 FALLS PROBLEME:
- Keine HDMI: TV-Input checken, Kabel probieren
- Keine WLAN: SSID/Passwort doppelt checken
- App lädt nicht: Server läuft? Firewall?
- Siehe: SETUP-ANLEITUNG.md → Troubleshooting

✅ ERGEBNIS:
