# Snova Studio

**Art:** KI Mobile App  
**Stack:** React Native (Expo) + Node.js/Express + Kie.ai  
**Status:** In Entwicklung  

## Was
- Konsistente Charakter-Erstellung mit KI
- Story-Video-Generierung (Grok, Sora 2, Veo 3.1)
- Admin-Panel für Coin-Management

## Tech
- **Backend:** Node.js 24, Express, SQLite (node:sqlite)
- **Mobile:** React Native 0.81, Expo SDK 54
- **KI:** Kie.ai (Video-Modelle + Nano Banana Pro für Bilder)
- **Datenbank:** SQLite

## Wichtige Ports
- Backend: Port 3000
- Frontend: Expo QR-Code

## Preise (Kie.ai)
- Grok 6s: 10-20 Coins
- Sora 2 10s: 30 Coins
- Veo 3.1 Fast 8s: 60 Coins
