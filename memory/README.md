# memory/ – Aufbau

| Ordner | Inhalt | Darf angewendet werden? |
|---|---|---|
| `regeln/` | aktive Regelwerke | **ja** – verbindlich |
| `projekte/` | Projektnotizen, Stand und Besonderheiten | ja |
| `quellen/` | Original-Uploads unverändert, zur Nachvollziehbarkeit | ja, als Beleg |
| `archiv/` | überholte Versionen | **nein** – nur lesen, nie reaktivieren oder mit aktiven Regeln mischen |
| `sessions/` | Chatübergaben (`CHATRESET`) | ja, als Kontext |

## Reihenfolge beim Einlesen

1. `MASTER-MEMORY.md` (Repo-Root) – Index
2. `MEMORY.md` (Repo-Root) – aktueller Arbeitsstand
3. Die für die Aufgabe relevante Datei aus `regeln/` oder `projekte/`

Nicht alles auf Vorrat laden. Token sparen.

## Änderungsregel

`regeln/` wird nur bei ausdrücklichem **„Lernupdate"** geändert.
`MEMORY.md` wird laufend fortgeschrieben.
